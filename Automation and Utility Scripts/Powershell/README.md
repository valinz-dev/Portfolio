# PowerShell Automation Scripts

This repository contains a collection of **PowerShell scripts** demonstrating automation for real-world IT workflows.

## Overview

These scripts are designed to:

- Automate repetitive tasks
- Improve efficiency in production environments
- Support system reliability and uptime

Each script includes **inline comments** to explain functionality, making it easy to understand and adapt.

## Focus Areas

- **Legal IT Automation:** Scripts for iManage automation and bug repair
- **System Administration:** General workflow and task automation
- **Efficiency Tools:** Scripts built to streamline repetitive processes

## Disclaimer

A large portion of my professional work cannot be shared publicly due to confidentiality.  
The examples here are for **demonstration purposes only** — they may require modifications to run in another environment.

## How to Use

1. Clone or download the repository
2. Open the script in PowerShell ISE or your preferred editor
3. Review comments and adapt parameters as needed
4. Execute scripts carefully in a test environment before using in production
