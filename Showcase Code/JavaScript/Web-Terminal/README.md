# Web-Terminal

**Web-Terminal** is an interactive, terminal-inspired interface built with HTML, CSS, and JavaScript. It mimics a command-line environment directly in the browser and serves as a unique front-end experience for showcasing personal projects, portfolio sections, or learning tools.

---

## Features

- Terminal-style UI with a fixed-size viewport.
- Interactive command input for navigation:
  - `!welcome` – Displays a personalized welcome message.
  - `!about` – Navigates to the About Me section.
  - `!cv` – Navigates to the CV section.
  - `!fost` – Navigates to the Focus ST Build section.
  - `!portfolio` – Navigates to the Projects section.
- Responsive design that works across devices.
- Fully open-source and customizable.
